اربط قاعدة بيانات متجرك

اللوحة تستخدم قاعدة بياناتك في Supabase. أنشئ مشروعًا مجانيًا، شغّل ملف الإعداد، وأدخل مفتاح النشر العام هنا.

  1. أنشئ مشروعًا من لوحة Supabase.
  2. من Authentication → URL Configuration أضف رابط الإدارة إلى روابط التحويل المسموح بها، ثم ادعُ المالك من Authentication → Users.
  3. من SQL Editor استبدل replace-with-your-email@example.com بالبريد الذي دعوته، والصق ملف supabase/setup.sql ثم شغّله.
  4. من Project Settings → API انسخ رابط المشروع ومفتاح anon / publishable. لا تستخدم أبدًا مفتاح service_role.
